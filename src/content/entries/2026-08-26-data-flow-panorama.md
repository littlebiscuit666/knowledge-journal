## 一、完整数据库类型全景

按**用途**分，数据库至少有 10 种类型：

```
数据库类型
    │
    ├── 1. 关系型（RDBMS）     ── MySQL、PostgreSQL、Oracle、SQL Server
    ├── 2. 文档型（Document）  ── MongoDB、CouchDB、RethinkDB
    ├── 3. 键值型（KV）        ── Redis、Memcached、LevelDB、RocksDB
    ├── 4. 时序型（Time Series）── InfluxDB、TimescaleDB、Prometheus、QuestDB
    ├── 5. 搜索引擎（Search）   ── Elasticsearch、Solr、OpenSearch、Meilisearch
    ├── 6. 图数据库（Graph）    ── Neo4j、JanusGraph、TigerGraph、NebulaGraph
    ├── 7. 宽列存储（Wide-Column）── Cassandra、HBase、ScyllaDB
    ├── 8. 分析型（OLAP）       ── ClickHouse、Doris、StarRocks、Snowflake、BigQuery、DuckDB
    ├── 9. 消息队列（Queue）    ── Kafka、RocketMQ、RabbitMQ、Pulsar
    └── 10. 对象存储（Object）   ── S3、OSS、MinIO、HDFS、Ceph
```

## 三、补充：每种专门数据库的典型场景

### 1️⃣ 时序数据库（Time Series Database）

**专门存"带时间戳的数据"，比如监控指标、传感器读数**

| 场景                    | 数据示例                           |
| ----------------------- | ---------------------------------- |
| **服务器监控**    | CPU 使用率、内存、磁盘，每秒一个点 |
| **物联网（IoT）** | 温度、湿度、设备状态               |
| **业务监控**      | 每分钟的下单量、在线人数           |
| **金融行情**      | 股票价格、汇率，毫秒级             |
| **APM**           | 应用响应时间、错误率               |

**代表产品**：

| 数据库                | 特点                       |
| --------------------- | -------------------------- |
| **InfluxDB**    | 最流行，写入性能强         |
| **TimescaleDB** | 基于 PostgreSQL，SQL 友好  |
| **Prometheus**  | 监控领域事实标准（拉模式） |
| **TDengine**    | 国产、IoT 场景强           |
| **QuestDB**     | 高性能、支持 SQL           |

---

### 2️⃣ 文档数据库（Document DB）

**存灵活的 JSON 文档，Schema 不固定**

| 场景                      | 数据示例                 |
| ------------------------- | ------------------------ |
| **内容管理（CMS）** | 文章、博客，每篇字段不同 |
| **产品目录**        | 不同品类商品属性差异大   |
| **用户画像**        | 标签灵活变动             |
| **移动 App 后端**   | 快速迭代                 |
| **游戏数据**        | 玩家配置、道具           |

**代表产品**：MongoDB、CouchDB、Firestore、DynamoDB

---

### 3️⃣ 键值数据库（KV Store）

**最快的 KV 查找，常用于缓存**

| 场景               | 数据示例               |
| ------------------ | ---------------------- |
| **缓存**     | 用户 session、热点数据 |
| **限流计数** | 接口调用次数           |
| **排行榜**   | 实时分数               |
| **分布式锁** | 协调多服务             |

**代表产品**：Redis、Memcached、KeyDB、Tair

---

### 4️⃣ 搜索引擎（Search Engine）

**全文检索 + 复杂过滤 + 聚合**

| 场景               | 数据示例                   |
| ------------------ | -------------------------- |
| **电商搜索** | 商品名称、描述全文搜       |
| **日志检索** | ELK Stack（Elasticsearch） |
| **应用搜索** | APP 内内容搜索             |
| **向量检索** | RAG、推荐系统              |

**代表产品**：Elasticsearch、Solr、OpenSearch、Meilisearch

---

### 5️⃣ 图数据库（Graph DB）

**存实体关系，擅长多跳查询**

| 场景               | 数据示例         |
| ------------------ | ---------------- |
| **社交网络** | 好友关系、关注链 |
| **知识图谱** | 实体关系         |
| **反欺诈**   | 关联账户识别     |
| **推荐系统** | 协同过滤         |

**代表产品**：Neo4j、NebulaGraph（国产）、TigerGraph

---

### 6️⃣ 宽列存储（Wide-Column）

**超大规模写入，列族灵活扩展**

| 场景                 | 数据示例     |
| -------------------- | ------------ |
| **历史消息**   | 聊天记录     |
| **物联网时序** | 设备历史数据 |
| **风控日志**   | 行为流水     |

**代表产品**：Cassandra、HBase、ScyllaDB

---

### 7️⃣ 向量数据库（Vector DB）⭐ 新热门

**专门存向量，做相似度搜索**

| 场景                 | 数据示例          |
| -------------------- | ----------------- |
| **RAG 知识库** | LLM 检索增强      |
| **图像搜索**   | 以图搜图          |
| **推荐系统**   | 用户/物品向量召回 |
| **人脸识别**   | 人脸特征向量      |

**代表产品**：Milvus、Weaviate、Qdrant、Pinecone、Chroma

## 六、学习重点建议

### 如果你刚开始学习

1. **关系型**（MySQL）— 必须掌握
2. **文档型**（MongoDB）— 了解概念
3. **OLAP**（DuckDB / ClickHouse）— 数据分析核心
4. **消息队列**（Kafka）— 了解架构
5. **时序**（InfluxDB）— 监控场景需要
6. **向量**（Milvus）— 现在很火，学 AI 必看

### 不需要全学

按需选择：

- 做业务后端 → MySQL + Redis + MongoDB
- 做数据分析 → ClickHouse + dbt
- 做运维监控 → Prometheus + InfluxDB
- 做 AI 应用 → Milvus + LLM
- 做搜索 → Elasticsearch

## 七、一句话总结

> **数据库种类繁多（10+ 种），每种针对特定场景优化**
>
> 数据流转 = **多种异构数据源** → **同步/采集** → **统一存储分析**
>
> 学习时**不必全学**，按你的工作场景选择性深入。
