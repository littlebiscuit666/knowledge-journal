### 错误模式统计（三批 15 题累计，比错题本身更重要）

1. **❶ 算法的「身份属性 + 机理细节」记不牢（20/35，头号问题）**——两层都要背：
   - 身份层：每个算法四个标签 `监督? / 生成? / 能分类? / 能降维?`（题1/4/5/22——无监督不止聚类，还有降维、关联规则）
   - 机理层：收敛条件（题8 感知器）、命门与适用边界（题7 BN）、加权机制与家族归属（题10/13/27 集成）、作用机理（题9 缩放）、复杂度方向（题14 核函数）、噪声↔滤波对应（题15）、分裂准则动机（题18 ID3/C4.5）、间隔系数（题23 SVM）、回归假设与 R²（题24）、核选择主次（题26）、分层采样作用（题29）、领域自适应边界（题30）、优化问题 vs 泛化问题（题35）
2. **❷ 审题不抓关键词 / 脑补升级概念**——「特征选择」（题2）、「主要优势」（题3）；题24 题面说 R² 就是普通 R²，脑补成 adjusted R² 反而选错。先圈关键词，**按字面走，升级概念题干不明示就不上**。
3. **❸ 多选题两端摇摆**——要么选不全（题5/9/10/25/28/29），要么干脆全选（题30）。规则：**放宽定义逐个检验 ≠ 全选；每一项都要能说出"它为什么属于"的机制，说不出来源就不选**。组合方法（如 Elastic Net = L1+L2）也是正经选项，别漏。
4. **❹ 对绝对化表述不设防（题6/7/29）**——「完全避免」「不适用于」「总是优于」在「找错误说法」题里就是答案信号。规则：**声称某方法"完全/彻底解决X""总是/必然Y" → 优先判错**；但描述机制本身的绝对句（如"输出恒为0"）不受此限。
5. **❺ 方向/排序类考点靠背不靠算（题14/17/19）**——"长短/大小/先后"纯硬背必记反。对策：**能代入就代入**（p=0.25 十秒算出不纯度排序）、**能想机制就想机制**（iForest"孤岛几刀就切出"）。
6. **域转移预警**：二批→深度学习训练技巧；三批→剪枝/核函数/图像滤波；四批→元学习·超网络/异常检测/决策树细节；五批→部署（ONNX）/数据挖掘（关联规则）/统计回归（线性回归）；六批→MLOps/迁移学习·领域自适应；七批→回到主线的应用题+计算题——常见+边缘+新潮域都扫到了，主战场仍是❶+❸+❺。11/12（剪枝、TF 考古题）、20/31/32/33（主线重复题）做了速记级处理。
7. **❼ 计算题不做合理性检查（题34）**——熵算对了却选了负号。**熵 ≥ 0、概率 ∈ [0,1]、准确率 ≤ 100%、损失 ≥ 0**：算完花 3 秒问"符号/量级合理吗"，不合理立即回查。

## 二、逐题精讲

### 题1：生成模型 vs 判别模型（答错：选了A，正确是B）

**题目**：以下属于生成模型的是？A 逻辑回归 / B 高斯混合模型 GMM / C SVM / D 随机森林

**核心定义**：
- **判别模型**：直接学习 **P(Y|X)** 或决策函数 f(X) —— 回答"给定X，Y是什么"
- **生成模型**：学习 **联合分布 P(X,Y)** 或 **P(X)** —— 回答"数据是怎么来的"，能**采样生成新样本**

**为什么 GMM 是生成模型**：GMM 学到了数据的概率密度 p(x)=ΣπₖN(x|μₖ,Σₖ)，拿到这个分布就能采样出新的数据点，所以是生成模型。它虽然是"聚类"算法（无监督），但**无监督 ≠ 非生成**——这是本题最大的认知陷阱。

**为什么错选逻辑回归**：LR 虽然建模概率 P(Y|X)，但那是**条件**概率，不含"数据本身怎么分布"的信息，造不出新样本 → 判别模型。

**必背分类表**：

| 判别模型 | 生成模型 |
|---------|---------|
| 逻辑回归 LR | 朴素贝叶斯 NB |
| SVM | 隐马尔可夫 HMM |
| 决策树 / 随机森林 | 高斯混合 GMM |
| KNN | 高斯判别分析 GDA |
| 神经网络 / 深度学习 | 主题模型 LDA(Latent Dirichlet Allocation) |
| 条件随机场 CRF | VAE / GAN / Diffusion / 大语言模型 |
| 线性回归(回归视角) | 贝叶斯网络 / RBM |

**记忆口诀**：**"贝叶斯一家（NB/GDA/贝叶斯网络）+ 序列(HMM) + 混合(GMM) + 主题(LDA) + 深度生成(VAE/GAN/Diffusion) = 生成；其余几乎全是判别。"**

**面试拷打角度**：
- 生成式 vs 判别式优缺点？→ 判别式通常准确率更高、特征工程省心；生成式小样本有优势、能处理缺失数据/新类别、能生成样本。
- LR 和 NB 的联系？→ 同是分类器，NB 是生成式（先学 P(X|Y)P(Y)），LR 是判别式（直接学 P(Y|X)）。

### 题2：正则化方法选择（答错：选了C，正确是B）

**题目**：高维数据 + 过拟合 + 特征冗余，要**同时**解决过拟合和**特征选择**，选哪个？
A L2 Ridge / B L1 Lasso / C Dropout / D Early Stopping

**题眼**：「同时」+「特征选择」→ 只有 L1 能把权重压到**精确为 0**，等于把该特征踢掉，天然完成特征选择。

**为什么错选 Dropout**：Dropout 是**神经网络专用**技巧（随机失活神经元防共适应），且题目场景未提神经网络；它防过拟合但**不做显式特征选择**。这题其实是送分题——看到"特征选择"三个字就选 L1。

**四种方法对比表（必背）**：

| 方法 | 原理 | 特征选择？ | 适用场景 |
|------|------|-----------|---------|
| **L1 / Lasso** | 权重绝对值惩罚，产生**稀疏解** | ✅ 是 | 高维+特征冗余（本题场景） |
| **L2 / Ridge** | 权重平方惩罚，权重整体变小但不为0 | ❌ 否 | 多重共线性、一般防过拟合 |
| **Dropout** | 训练时随机失活神经元 | ❌ 否 | 仅神经网络 |
| **Early Stopping** | 验证集性能不再提升就停 | ❌ 否 | 任何迭代训练，最便宜的防过拟合 |

**为什么 L1 能压到 0 而 L2 不能**（面试高频）：
- 几何角度：L1 的约束域是**菱形**，棱角尖在坐标轴上，损失函数等高线容易在顶点处相切 → 某些权重恰好为 0；L2 约束域是**圆形**，没有棱角，切点一般不在轴上。
- 优化角度：|w| 在 0 处导数不存在（次梯度不为零），权重可以"停"在 0；w² 在 0 处梯度为 0，权重只会无限接近 0。

**补充**：L1+L2 结合 = **Elastic Net**（特征多且相互相关时比纯 L1 稳）。

### 题3：矩阵分解 vs 协同过滤（答错：选了C，正确是B）

**题目**：推荐系统中，矩阵分解相比协同过滤的主要优势是？
A 更擅长冷启动 / B 能自动学习特征的隐含语义关系 / C 计算复杂度显著降低 / D 无需用户行为数据

**正确逻辑**：MF 把评分矩阵 R 分解为 R ≈ P·Qᵀ，用户和物品各得到一个**隐因子向量**（latent factors），这些维度是模型**自己学出来的**，自动捕获"用户偏好和物品属性的潜在结构"（比如自动学出"价格敏感度""风格偏好"这种没人标注过的维度）→ 选 B。

**逐项排除**：
- A 冷启动：MF 和邻域 CF **都依赖历史行为**，新用户/新物品都没行为 → 一样差。冷启动要靠内容特征/热门推荐兜底。
- C 复杂度：MF 训练要 SGD/ALS **迭代优化**，并不"显著降低"。邻域法预测虽然简单，但复杂度从来不是 MF 的卖点。
- D 无需行为数据：两句话驳倒——没有行为数据，评分矩阵都不存在，MF 无从分解。

**概念修正（面试可能拷打）**：广义上 MF 本身就是协同过滤的一种（**model-based CF**），题目说的"协同过滤"其实指**基于邻域的 memory-based CF**（UserCF/ItemCF）。回答时先点破这层，再比较"MF vs 邻域法"：

| | 邻域 CF (UserCF/ItemCF) | 矩阵分解 MF |
|---|---|---|
| 相似度 | 显式计算（余弦/皮尔逊） | 隐式，分解中自动学习 |
| 泛化 | 只看相似用户/物品，**泛化弱** | 隐向量对没交互过的 (u,i) 也能打分 |
| 可解释性 | 强（"买了X的人也买了Y"） | 弱 |
| 数据稀疏 | 敏感 | 更鲁棒 |

**延伸链**：MF(FunkSVD/BiasMF) → FM/FFM（加特征交叉）→ 双塔/DeepFM/DIN（深度推荐）。面试答"了解推荐算法演进"时用得上。

### 题4：不能直接用于文本分类的算法（答错：选了B，正确是A）

**题目**：以下哪些方法**不可以直接**来对文本分类？A K-means / B 决策树 / C SVM / D KNN

**这道题错得最需要警惕**——决策树当然能做文本分类，而 K-means 是**聚类**（无监督），根本没有"标签"概念，谈不上分类。方向完全反了，说明监督/无监督的边界还没建起来。

**核心规则一句话**：**有标签才能"分类"。分类/回归 = 监督；聚类/降维 = 无监督。K-means 是聚类，不能直接分类。**

**决策树/SVM/KNN 为什么能文本分类**：文本分类的标准流程 = 分词 → 文本向量化（TF-IDF / 词袋 / 词向量）→ 喂给任意监督分类器。B、C、D 都是经典监督分类器，"直接用"没问题。

**算法监督属性速查（❶错误模式的解药，必背）**：

| 监督（分类/回归） | 无监督（聚类） | 无监督（降维） |
|---|---|---|
| LR、SVM、决策树、随机森林、GBDT/XGBoost | K-means、层次聚类、DBSCAN、GMM聚类 | PCA、SVD、LDA(线性判别)、t-SNE、自编码器 |
| KNN、朴素贝叶斯、神经网络、CRF | — | 小波变换、Laplacian Eigenmaps、LLE、MDS |

**辨析**："聚类结果能不能用于分类？"——可以**间接**用（聚类产生伪标签再训练、聚类辅助特征工程），但题目问的是"**直接**"，所以不行。选择题抠字眼："直接"两个字就是排除项的开关。

### 题6：Dying ReLU 神经元死亡（正确是C，我的答案未标注）

**题目**：关于"神经元死亡"哪个描述**错误**？A 恒负输入→输出恒0、梯度恒0 / B 死后可能整个训练都无法再激活 / C 小学习率可**完全避免** / D Leaky/PReLU 负区间给小斜率缓解

**核心机理**：ReLU(x)=max(0,x)。若某神经元对所有样本的加权和 z 恒为负 → 输出恒 0、该处导数恒 0 → 梯度传不回来 → w、b 永不更新 → 永久失活。典型诱因：一次过大的梯度更新把偏置推得很负（大学习率下高发）。

**为什么 C 错**：小学习率只是**降低**触发概率（不容易一次把权重推飞），但只要输入持续为负，梯度照样恒 0，照样会死。**"完全避免"是绝对化承诺——这正是 ❹ 模式的标准考法。**

**A/B/D 为什么对**：A 就是死亡的定义（绝对句但描述的是机制本身，机械成立）；B 用词是"**可能**"无法再激活，严谨；D 正确——负区间有小斜率，死区梯度不为 0。

**面试拷打角度**：
- ReLU 为什么流行？→ 正区间导数恒 1（缓解梯度消失）、计算便宜、稀疏激活
- 梯度消失 vs 神经元死亡？→ 消失 = 饱和区导数**很小**（学得慢但还在学）；死亡 = 导数**恒 0**（彻底躺平）
- 缓解全家桶：Leaky/PReLU/ELU/GELU、较小学习率、He 初始化、BatchNorm、梯度裁剪

### 题7：BN 批归一化（答错：选了D，正确是B）

**题目**：关于 BN 说法**错误**的是？A batch尺寸受硬件限制 / B **不适用于**RNN / C 通常在卷积后 / D batch-size小效果不明显

**BN 机理一句话**：对每个 mini-batch 的每个特征（CNN 里=每个 channel），用 batch 内均值/方差把激活值归一到 N(0,1)，再经 γ、β 仿射还原；**训练用 batch 统计，推理用训练期的滑动平均**——行为不一致是面试常问点。

**为什么错选 D**：D 恰恰是 BN 的著名命门——batch 小 → 均值方差估计噪声大 → 归一化不稳 → 效果打折。这说法是对的。检测/分割里 batch 只有个位数，正是 GroupNorm 的诞生动机。

**为什么 B 错（正确答案）**：「不适用」太绝对。BN 用于 RNN 有困难（序列变长、各时间步统计量波动），实践更常用 LayerNorm，但「有困难、不常用」≠「不适用」——Recurrent Batch Normalization 等工作证明改造后可用。**绝对词「不适用」就是答案信号（❹）。**

**面试拷打角度**：
- BN 放哪？→ Conv 之后、激活之前（Conv → BN → ReLU）
- 为什么小 batch 伤 BN / 检测分割怎么办？→ 统计不准 → GroupNorm
- Transformer 为什么用 LN？→ 变长序列 batch 统计不稳 + LN 与 batch 无关、训练推理一致

### 题8：感知器与线性不可分（答错：选了A，正确是B）

**题目**：类域界面方程法中，**不能**求线性不可分情况近似/精确解的是？A 伪逆法 / B 感知器 / C 二次准则H-K / D 势函数法

**核心**：**感知器收敛定理——只有训练样本线性可分时，感知器才收敛；不可分时权向量来回震荡，永远得不到解。** 其他三个都"最小化某种误差"，不挑数据：
- 伪逆法：w = X⁺y 最小二乘闭式解，任何数据都有解 → 能给最优近似解
- H-K 算法：最小化 ‖Xw−b‖² 且同时调 margin 向量 b>0（二次准则）→ 能
- 势函数法：累积势函数确定边界，可逼近不可分边界 → 能

**错因**：选了 A——对"伪逆"这个冷门名词不熟，就把"不熟"当"不能"。**判断"能不能"必须依据机理而不是熟悉度：只认可分数据的迭代修正型 → 不能；误差最小化的有解优化型 → 能。**

**现代对应（面试话术）**：感知器局限 → Pocket 算法（另存最优权向量）、平均感知器、软间隔 SVM（松弛变量处理不可分）。

### 题9：特征缩放（多选，答错：选了AC，正确是ABC）

**题目**：特征缩放哪些说法正确？A 加速收敛 / B 提高准确性 / C 降低过拟合风险 / D 对所有算法适用

**漏选 B 的根因**：把缩放理解成"只整理数值、只影响速度"，忽略了它会**改变算法的输出结果**——距离类算法里，未缩放时大尺度特征（收入 0~100000）会**淹没**小尺度特征（年龄 0~100），距离被前者主导；缩放后各特征公平参与 → KNN/K-means/SVM 的准确率实打实提高。**缩放不仅影响"多快收敛"，还影响"收敛到哪"。**

**逐项**：
- A ✅ 梯度下降视角：特征尺度悬殊 → 损失面椭圆拉长 → 折线震荡；缩放后近圆 → 直奔最优
- B ✅ 距离视角（如上）
- C ✅ 正则化公平性：未缩放时大尺度特征系数天然偏小，L1/L2 惩罚力度失衡；缩放后正则化才能一视同仁 → 间接防过拟合
- D ❌ 树模型按"单特征阈值"分裂，对单调缩放完全免疫，不需要缩放——「所有」一词即破绽

**方法与坑（面试加分点）**：Min-Max 归一化（[0,1]，受异常值支配）/ Z-score 标准化（最常用）/ RobustScaler（中位数+IQR，抗异常值）。**防泄漏：scaler 只在训练集 fit，测试集只 transform。**

**必背边界**：需要缩放 = 梯度下降类（LR/NN）+ 距离类（KNN/K-means/SVM/PCA）；不需要 = 树模型（决策树/RF/GBDT/XGBoost）+ 朴素贝叶斯。

### 题16：超网络 + 元学习做少样本学习（答错：选了D，正确是B）

**题目**：如何有效结合超网络与元学习提升少样本学习效果？

**先补概念（这题考的就是名词本身）**：
- **超网络 HyperNetwork**：不直接学主网络的权重，而是训一个"生网络" **f(条件) → 生成主网络的权重**，条件可以是任务 ID、support set 特征等
- **元学习（少样本场景）**：在大量小任务上学会"怎么学"，新任务只给 N-way K-shot 几个样本也能快速适配。三大流派：

  - 度量式：孪生网络 / 原型网络，学个距离度量直接比对分类

**为什么 B 对**：超网络以 support set 为条件**生成新任务的初始化参数**，参数天生"预适配"新任务 → 少样本也够用。这正是两条技术的正确接法。

### 题17：Isolation Forest 异常点路径长度（答错：选了A，正确是B）

### 题19：三种不纯度的大小关系（答错：选了A，正确是C）

**题目**：二分类中，基尼指数、分类误差率、二分之一熵的大小关系？

**别背排序——10 秒代入 p=0.25 直接算**：

| 度量 | 公式 | p=0.25 的值 |
|---|---|---|
| 分类误差率 | min(p, 1−p) | **0.25** 最小 |
| 基尼指数 | 2p(1−p) | **0.375** 居中 |
| 二分之一熵 | ½·H(p) | **0.406** 最大 |

→ **分类误差率 < 基尼指数 < 二分之一熵**（只在 p=0、0.5、1 处三者相等）。你选的 A 把前两个顺序颠倒了。

**理解层**：误差率只数"分错概率"最粗糙；基尼是它的平滑版；熵对不确定性最敏感（凹得最深）。

**顺带记**：CART 用基尼是因为免算 log、快；三种度量长出来的树差别不大。

### 题21：ONNX Runtime 推理加速（正确 B，我的答案未标注）

**题目**：ONNX Runtime 对比直接用 PyTorch 推理的主要优势？

### 题22：关联规则挖掘（找错误说法，正确 C，我的答案未标注）

### 题24：线性回归假设判断（答错：选了A，正确是D）

### 题34：信息熵计算（答错：选了B，正确是A）—— 数对了，符号错了

**题目**：7 个标签 [1,1,1,1,0,0,0] 的熵近似值（log3/7=−0.847，log4/7=−0.560）？

**计算五步**：
1. P(1) = 4/7，P(0) = 3/7
2. H = −P(1)·log P(1) − P(0)·log P(0)
3. 代入：H = −(4/7)×(−0.560) − (3/7)×(−0.847)
4. = 0.320 + 0.363
5. **= 0.683** → 选 A

你算出了 0.683 却选了带负号的 B——**熵永远非负**：每一项 −p·log p 在 p∈(0,1) 时 log p<0，所以每项 ≥0，总和 ≥0（完全纯净 = 0，二分类最大 ≈ 1）。

**❼ 新规则：计算题算完花 3 秒做合理性检查**——熵 ≥ 0、概率 ∈ [0,1]、准确率 ≤ 100%、损失 ≥ 0。符号/量级不对立即回查，这种分丢得最冤。

### 题35：神经网络不收敛的原因（答错：选了C，正确是B）

**题目**：哪个**不是**不收敛的原因？A 没做归一化 / B **网络太深+数据太少** / C 学习率过大 / D 网络中大量梯度为 0

**判别关键：「不收敛」是优化问题，「过拟合」是泛化问题——两码事。**

### 3.3 过拟合全家桶（详见题2）

**过拟合信号**：训练集好、验证/测试集差。
**药方清单**（面试要求"说出至少4种"）：
1. 更多数据 / 数据增强
2. 正则化：L1（顺带特征选择）、L2
3. 神经网络专用：Dropout、BatchNorm、权重衰减
4. Early Stopping
5. 降低模型复杂度（减层/减树深）
6. 集成：Bagging（随机森林）
7. 交叉验证选超参

**欠拟合**则相反：训练集都学不好 → 加特征/加大模型/减小正则。

### 3.4 常见监督算法一句话人设

| 算法 | 一句话 | 关键词 |
|---|---|---|
| 逻辑回归 | 线性模型+sigmoid，输出概率 | 判别、线性、可解释 |
| SVM | 最大间隔超平面，核技巧处理非线性 | 判别、小样本强、凸优化 |

| 随机森林 | 决策树 Bagging + 特征随机 | 抗过拟合、并行 |
| GBDT/XGBoost | 决策树 Boosting，逐步拟合残差 | 竞赛神器、串行 |
| KNN | 惰性学习，找K个最近邻投票 | 无训练、对K和距离度量敏感 |

### 3.5 推荐系统（详见题3）
邻域CF → MF（隐因子）→ FM → 深度模型。冷启动靠内容特征，不是靠 MF。

### 3.6 激活函数家族（详见题6）

| 激活函数 | 要点 | 短板 |
|---|---|---|
| Sigmoid | 压到(0,1)；输出层二分类专用 | 两端饱和→梯度消失；非零中心；计算贵 |
| Tanh | (-1,1)，零中心 | 仍饱和 |
| ReLU | max(0,x)；CNN/MLP 默认 | **Dying ReLU** |
| Leaky ReLU | 负区间给小斜率 αx（α≈0.01） | α 要手调 |
| PReLU | α 可学习 | 略增参数 |
| ELU | 负区间指数曲线，输出近零中心 | 含 exp 稍贵 |
| GELU | 平滑概率门控 | Transformer/BERT 默认 |

选型口诀：隐藏层默认 ReLU，遇死亡换 Leaky/PReLU/GELU；输出层看任务（sigmoid/softmax/线性）。

### 3.7 归一化家族（详见题7）

| 方法 | 归一化维度 | 适用 | 短板 |
|---|---|---|---|
| BatchNorm | 同特征跨样本（batch内） | CNN 较大 batch | **命门=batch小**；训练/推理行为不一致 |
| LayerNorm | 单样本全部特征 | RNN / Transformer | 与 batch 无关 |
| InstanceNorm | 单样本单通道 | 风格迁移 | 丢全局对比度 |
| GroupNorm | 单样本分组通道 | 小 batch（检测/分割） | — |

- BN：训练用 batch 统计，推理用滑动平均
- CV 顺序：Conv → BN → ReLU
- Transformer 用 LN：变长序列 batch 统计不稳 + LN 训练推理一致

### 3.8 集成学习：Bagging vs Boosting（详见题10/13）

| | Bagging | Boosting |
|---|---|---|
| 训练方式 | 并行，有放回采样 | 串行，后一轮关注前一轮错样本 |
| 基分类器权重 | **相等（等权投票）** | 按**训练误差**加权 |
| 样本权重 | 不变 | 分错按同比例放大（AdaBoost） |
| 主要作用 | 降**方差** | 降**偏差** |
| 抗噪声 | 强（RF 是抗噪代表） | 弱（对标签噪声敏感） |
| 代表 | 随机森林 | AdaBoost / GBDT / XGBoost / LightGBM |

**XGBoost vs GBDT（题13）**：同属 Boosting；XGBoost = GBDT 的工程强化——二阶泰勒展开、目标函数自带正则项、列采样、特征级并行。

### 3.9 特征工程：缩放（详见题9）

- 方法：Min-Max（[0,1]，怕异常值）/ Z-score（最常用）/ RobustScaler（中位数+IQR）
- 三大作用：**加速**（损失面椭圆变圆）、**提准**（距离不被大尺度特征主导）、**防过拟合**（正则化惩罚对各特征公平）
- 需要缩放：梯度下降类（LR/NN）+ 距离类（KNN/K-means/SVM/PCA）
- 不需要：树模型（按单特征阈值分裂，对单调缩放免疫）+ 朴素贝叶斯
- **防泄漏：只在训练集 fit，测试集 transform**

### 3.10 线性分类器的收敛性（详见题8）

- **感知器收敛定理**：线性可分 ⇔ 有限步收敛；不可分 → 震荡不收敛
- 伪逆/最小二乘/LMS/H-K（二次准则）：最小化平方误差，**永远有解** → 不可分也能给近似解
- 不可分的现代解法：Pocket / 平均感知器 / 软间隔 SVM
- 判断口诀：迭代修正型且只认可分 → 不能；误差最小化型 → 能

### 3.11 决策树过拟合与剪枝（详见题11）

- 过拟合原因：树太深、叶子太纯（等于背题）
- **预剪枝**：分裂前刹车——max_depth、叶子最少样本数、最小分裂增益、验证集不再提升
- **后剪枝**：长满再自底向上剪（代价复杂度剪枝 CCP）
- 配套：RF 降方差；GBDT 靠学习率+子采样+限深

### 3.12 模型复杂度与偏差-方差（统摄题2/11/13/14，面试最爱）

**泛化误差 = 偏差² + 方差 + 噪声**
- 偏差大 = 模型太简单拟合不动 → 欠拟合
- 方差大 = 模型太复杂对扰动敏感 → 过拟合
- 防过拟合手段全部 = **降方差**的某个角度：正则化（压权重）、剪枝（砍树）、Dropout（稀释共适应）、加数据（方差∝1/n）、清洗噪声、特征选择（题20）
- ⚠️ 反向操作：**增加迭代次数会加重过拟合**——正解是 Early Stopping（题20）
- **Elastic Net = L1+L2 同时用**：特征多且相互相关时比纯 L1 稳（题2 补充、题25 正式考——多选别漏）
- 🚨 **训练进程方向（题27，三考钉子）**：训练不足 → **偏差**主导（欠拟合端）；训练充足 → **方差**主导（过拟合端）。**Boosting 降偏差 / Bagging 降方差**——题10/13/27 三次考试，必钉死
- **场景速判（题31）**：训练误差≈0 + 测试误差高 = 高方差（过拟合）→ 简化/加数据/正则化；训练误差也高 = 高偏差（欠拟合）→ 加复杂度/加特征。**先判病，再开药**
- Bagging 主要降方差，Boosting 主要降偏差
- **复杂度阶梯**：线性 < 低阶多项式核 < 高阶多项式 < 高斯RBF（无穷维）< 深层网络
- 一句话：升复杂度 → 偏差降、方差升；过拟合药方 = 往回拉复杂度 或 加数据

### 3.13 图像滤波（详见题15，域外低频）

椒盐噪声→**中值滤波**；高斯噪声→均值/高斯滤波；保边去噪→双边滤波（空间距离+灰度差双权重）；直方图与图像是多对一。记住对应关系即可。

### 3.14 决策树三兄弟：ID3 / C4.5 / CART（详见题18/19）

| | ID3 | C4.5 | CART |
|---|---|---|---|
| 分裂准则 | 信息增益 | 信息增益率 | 基尼(分类)/MSE(回归) |
| 特征类型 | 只能离散 | 连续可二分 | 连续+离散 |
| 树结构 | 多叉 | 多叉 | **严格二叉** |
| 剪枝 | 无 | 悲观剪枝 | 代价复杂度剪枝 CCP |
| 缺失值 | 不处理 | 能处理 | 能处理(代理分裂) |
| 任务 | 分类 | 分类 | 分类+回归 |
| 硬伤 | 多值偏好 | **慢** | — |

- 信息增益 = 划分前熵 − 划分后条件熵；增益率 = 增益 / IV（分裂信息，特征取值越多 IV 越大）
- **动机链**：ID3 偏好多值特征 → C4.5 用增益率治它 → 增益率又偏好少值 → 工程启发式（先按增益圈候选，再比增益率）

**不纯度三度量（二分类）**：误差率 min(p,1−p) < 基尼 2p(1−p) < ½熵 ½H(p)
**代入法**：p=0.25 → 0.25 < 0.375 < 0.406，十秒出排序，不硬背（❺ 的解药）
**熵计算模板（题34）**：H = −Σpᵢ·log pᵢ；**熵永远非负**（每项 −p·log p ≥ 0），二分类最大 ≈ 1。实算：[1×4, 0×3] → −(4/7)log(4/7) − (3/7)log(3/7) = 0.320 + 0.363 = **0.683**

### 3.15 异常检测：Isolation Forest（详见题17）

- 机制：随机特征 + 随机切分值 → iTree 森林；**异常点=孤岛，路径短**；异常分数 ∝ 1/平均路径长度
- 无监督、子采样、限深（≈log₂子样本数）→ 近似线性复杂度，大数据场景常用
- 家族：LOF（局部密度）、One-Class SVM（边界）、DBSCAN（密度聚类标噪声）

### 3.16 元学习与超网络（详见题16，前沿概念）

- **元学习 = 学会学习**：大量小任务上训"适配能力"，新任务 N-way K-shot 少样本快速适配
- 三大流派：**优化式** MAML（学好初始化，几步梯度收敛）/ **度量式**（孪生、原型网络）/ **生成式**（超网络直接生成参数）
- **超网络 HyperNetwork**：f(条件) → 主网络权重；配元学习 = 看 support set 生成初始化参数（"零梯度适配"）
- 亲戚：One-Shot NAS 也是超网络思路（生成子网络权重）

### 3.17 模型部署：ONNX 与推理加速（详见题21）

- **ONNX** = 跨框架模型交换格式；链路：PyTorch/TF 训练 → 导出 ONNX → ONNX Runtime/TensorRT 部署
- **ONNX Runtime 快在两处**：① 图优化（算子融合 Conv+BN+ReLU、常量折叠、冗余节点消除）② 硬件后端（Execution Provider：CUDA/TensorRT/OpenVINO）+ 内存复用；对比 eager mode 通常 2~5×
- 只推理不训练；PyTorch 侧对应加速 = torch.compile / TorchScript

### 3.18 关联规则挖掘：Apriori（详见题22）

- **两步**：min 支持度 → 频繁项集；min 置信度 → 关联规则。**无监督**（发现知识，无标签）
- 度量：Support = P(A∪B)；Confidence = P(B|A)；**Lift = P(B|A)/P(B)**（>1 正向、=1 独立、<1 负相关）
- **先验原理（反单调性）**：频繁项集的子集必频繁 ⇔ 非频繁项集的超集必非频繁 → 剪枝
- 算法：Apriori（多层迭代+剪枝）、FP-Growth（FP 树免候选集，更快）——面试可延伸

### 3.19 SVM 细节：间隔、损失与核选择（详见题23/26）

- **总间隔 = 2/‖w‖**（±1 两边界间距）；单侧距离 1/‖w‖；最大化间隔 ⇔ min ½‖w‖²
- 目标拆解：**Hinge 损失** Σmax(0, 1−y·f(x)) = 经验风险；**‖w‖²/2 正则项** = 结构风险（管间隔/泛化）
- 软间隔：松弛变量 ξ + 惩罚 C——C 大 → 看重经验风险 → 噪声敏感（题10 呼应）
- **核选择（题26）**：主要看**数据分布**（线性可分→线性核；非线性→RBF 默认；有先验→定制核）；样本量只是计算层次要因素
- 实操：高维稀疏（文本）先试线性核；核矩阵 n×n → 大样本 SVM 慢
- 支持向量：只有边界上/违反 margin 的点决定超平面

### 3.20 线性回归：假设与 R²（详见题24/25）

- 经典假设：线性 + 残差零均值等方差无相关（Gauss-Markov ⇒ BLUE）；**正态性**在区间估计/假设检验时需要
- **OLS 残差与自变量正交**（Xᵀe = 0，构造保证）——"残差和自变量不一定独立"是错误说法
- **R² = 1 − SSE/SST**，训练集上**加变量单调不减**；模型对比用 **Adjusted R²**（自由度惩罚，可能降）
- 残差方差无偏估计：σ̂² = SSE/(n−p)，p = 参数个数（含截距）
- 正则化全家：L1(Lasso) / L2(Ridge) / **Elastic Net（L1+L2）**

### 3.21 MLOps：数据版本管理（详见题28）

- **版本管理三件事**：变更历史（何时增删改）、可复现（回滚到任意历史版本）、**数据血缘**（原始数据→特征→训练集→模型 端到端追溯）
- 工具：DVC、lakeFS；**不直接提升精度**，是基础设施
- MLOps 全景一句话：版本控制（数据/代码/模型）+ CI/CD + 监控

### 3.22 类别不平衡与采样（详见题29）

- **分层采样**：划分 train/test 时保持类别**比例**——它不解决不平衡，只是不让划分歪掉
- **解决不平衡**：过采样（SMOTE 合成少数类）、欠采样、类别加权、阈值调整；评估用 F1/AUC 不用 accuracy
- "RF 总是优于单树"不成立：小数据、要可解释时单树更优——「总是/一定」= ❹ 信号
- **实战信号（题32）**：阳性 3% + accuracy 97% + recall 15% = **准确率悖论**（全预测阴性也能 97%）；提召回 → 过采样阳性。注：**交叉熵 = 对数损失**（二分类同一个东西，换损失 ≠ 换策略）

### 3.23 迁移学习与领域自适应（详见题30）

- 迁移学习谱系：预训练-微调（最常用）→ 领域自适应（Domain Adaptation）→ 多任务学习
- **领域自适应三挑战**：目标域分布变化大、缺目标域标签、领域间特征不一致
- 常用方法：特征对齐（MMD）、对抗对齐（DANN）、伪标签自训练
- **不属于它的**：标签不平衡（那是类别不平衡问题）、"过拟合源域"——判定标准 = 是不是"域间差异"范畴

### 3.24 训练不收敛排查清单（详见题35）

**先分清两种病**：loss 不降/震荡/爆炸 = **优化问题**；训练好测试差 = **泛化问题（过拟合）**。别混。

| 优化问题症状 | 原因 | 药 |
|---|---|---|
| loss 震荡/发散 | 学习率过大 | 调小、warmup、衰减 |
| 收敛极慢 | 未归一化、学习率过小 | 标准化/归一化、调大 |
| loss 卡住不动 | 梯度消失/死亡 ReLU | Leaky/GELU、BN、He 初始化、残差连接 |
| 训练好测试差 | 过拟合（泛化） | 3.12 全家桶 |
