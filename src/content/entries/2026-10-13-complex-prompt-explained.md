> 日期：2026-10-13
> 结论先行：**复杂提示词 = 把"模型自己脑补的自由"全部收回来，替它做每一个决定。**
> 复杂度不在字数多，在**约束的数量 + 约束之间互相咬合**。

---

## 一、一句话理解

- **简单提示词**：只说"画什么"，剩下的全靠模型发挥。
  例：`修表匠在修一块怀表。`
- **复杂提示词**：连"光从哪来、影子往哪投、螺丝有几颗、刀尖能不能碰到齿轮"都替模型定死。

## 二、九类约束（复杂度的完整清单）

以自己写的怀表提示词为例：

| # | 约束类型 | 怀表提示词里的原话 | 翻车难度 |
|---|---------|-------------------|:---:|
| ① | 镜头/视角 | 俯视微距、f/2.0浅景深、8k | 低 |
| ② | 主体 | 拆开后盖的纯铜机械怀表，露出齿轮 | 低 |
| ③ | 空间布局 | 螺丝正上方、放大镜左上角、笔记右下角、台灯左下角 | 中 |
| ④ | 精确数量 | 四颗螺丝、间距均匀 | **极高**（模型最容易数错） |
| ⑤ | 材质颜色 | 纯铜、银色镊子、金色零件、泛黄羊皮纸、烫金 | 低 |
| ⑥ | 动作状态 | 镊子"正夹着"、螺丝刀"悬停**未触碰**" | **高**（否定式状态最难） |
| ⑦ | 文字渲染 | TIME ARCHITECT，清晰完整无乱码 | 高（中文更难） |
| ⑧ | 光影氛围 | 光源左下、低角度斜射、长影投向右上、暗角 | 中 |
| ⑨ | 风格 | 复古商业摄影 | 低 |

**九类全填满 = 教科书级复杂提示词。**

## 三、三级递进：复杂度从哪来

```
Lv1 简单：修表匠在修一块怀表。
    → 模型自己决定视角、手套、光线、桌上有什么，全靠猜。

Lv2 中等：俯视特写，一双戴黑手套的手在修一块打开的铜怀表，
         桌上放着镊子和一本泛黄的笔记。
    → 定了视角/主体/2件道具，其余仍自由。

Lv3 复杂：怀表提示词（9类约束全填满），
         连"螺丝刀不许碰到齿轮"这种否定式状态都写了。
    → 模型几乎零自由度。
```

从 Lv1 到 Lv3 = 把模型的自由度一个个没收。

## 四、可复用的中文填空模板（分区标注式）

```
【镜头】视角（俯视/平视/微距）+ 景深光圈 + 画质
【主体】核心对象 + 它的状态（打开/拆开/运转中）
【布局】每个物体 + 方位（正上方/左上角/右下角…，一件一件钉死）
【数量】每样东西几个 + "数量必须准确"
【材质】每样东西什么做的、什么颜色
【动作】谁在做什么 + 什么"不能做"（悬停未触碰/只伸出一只手）
【文字】要出现的文字原样写出 + "清晰完整无乱码"
【光影】光源位置 + 照射方向 + 阴影投向 + 氛围词
【风格】摄影/油画/动漫 + 质感词（商业广告质感/电影级光影）
```

## 五、复杂提示词的两种"物种"

1. **文生图类**（本笔记主讲）：单段长文 + 几十条约束交缠，考模型的空间/数量/文字执行力。
   - 极限形态：50方块提示词——整段只干一件事，把50个格子的位置约束钉死到零自由度。
2. **Agent系统提示词**（那些英文repo里的东西）：
   - 不是画画提示词，是"给AI员工写的岗位说明书+规章制度"——你是谁/必须做什么/禁止做什么/工具怎么调/违反怎么办。
   - 几千行英文法规条文，和文生图提示词不是一个赛道，**不用看**。

## 六、实测：各约束类型模型服从度（2026-10-13 怀表提示词横评）

同一提示词测 qwen-image-3.0 / wan2.6-t2i / z-image-turbo：

| 约束类型 | qwen-image-3.0 | wan2.6-t2i | z-image-turbo |
|---------|:---:|:---:|:---:|
| 视角 | ✅ | ⚠️ 斜俯视 | ✅ |
| 主体 | ✅ | ✅ | ✅ |
| 无指手套（细节） | ✅ | ❌ 全指 | ❌ 全指 |
| 精确数量（4颗螺丝） | ✅ | ✅ | ❌ 3颗 |
| 悬停未触碰 | ✅ | ⚠️ 碰到 | ⚠️ 贴近 |
| 英文文字渲染 | ✅ | ✅ | ✅ |
| 鹅颈台灯形状 | ✅ | ✅ | ❌ 球形灯 |
| 景深/暗角/光影方向 | ✅ | ⚠️ 无景深 | ✅ |
| **总分** | **13/13** | **10/13** | **8.5/13** |

**规律**：
- 数量约束是最弱维度（z-image数错螺丝），文字渲染反而是强项（三家全对）
- 否定式动作（"未触碰"）只有满分模型能做到
- 出考题时优先拿④数量、⑥否定式动作、⑦文字做干扰维度，区分度最大

## 七、和自出题的联系

- task1_hard_10x10 的每道题 = 把一条 Lv3 提示词拆成10个候选，每个候选只动九类约束中的**一类**里的一个原子差异
- 好干扰维度的选择顺序：数量 > 否定式动作 > 方位 > 材质颜色 > 风格
