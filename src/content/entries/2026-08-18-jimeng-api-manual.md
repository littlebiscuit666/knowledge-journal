## 一、总览：两个能力怎么分工

| | 文生图3.1 | 图生图3.0智能参考 | **即梦4.0（主将）** | 交互编辑inpaint |
|---|---|---|---|---|
| req_key | `jimeng_t2i_v31` | `jimeng_i2i_v30` | `jimeng_t2i_v40` | `jimeng_image2image_dream_inpaint` |
| 输入 | 纯文字 prompt | 1张图 + 文字指令 | **0~10张参考图** + prompt | 原图 + **mask** + prompt |
| 输出 | 全新生成图 | 编辑后的图 | 全新场景图，**角色身份从参考图带来** | 仅mask白区重绘，其余保持 |
| 漫画里的用途 | 出定妆照、抽卡 | 已弃用（脸部重绘诡异） | **批量产分镜格（一致性正解）** | 局部修补/消除笔（表情微调、修崩坏） |
| 特长 | 美感、风格、细节 | 海报图文（死穴：改表情） | 参考生图+多图融合+组图，4K | 黑区像素级保留，无全图漂移 |

**关键认知：漫画流水线 = 3.1 出定妆照 → 4.0 拿定妆照批量产分镜格。**

## 五、即梦4.0（jimeng_t2i_v40）—— 角色一致性正解 ★主力

同网关同SDK同密钥，2026-08-18 已实测跑通（本地base64可用，虽文档只写了image_urls）。

**与 3.x 的格式差异（踩坑）**：
- **没有 seed 参数**（传了可能被无视或报错）
- **默认按 prompt 意图输出多张图、按张计费** → 单图必须传 `"force_single": true`
- 输入图上限 15MB/张、4096×4096、宽高比[1/3,3]、最多10张（建议≤6张，多了参考效果降）
- 尺寸语义变了：默认 **2K(2048×2048) 智能判比例**；传宽高则面积须在 [1024×1024, 4096×4096]；过小分辨率易脸崩字崩，建议≥2K
- `scale` 仍是文本影响度(0~1默认0.5)；还有 `min_ratio`/`max_ratio` 可夹比例
- 输出 png（3.x 是 jpeg），URL 24h 有效

**组图模式（`force_single:false`）**：一次最多出 15-输入张数 张内容关联图——漫画分镜页专用；但耗时随张数显著变长，官方建议组图控制在9张内，并明确指定分辨率。

**提示词建议（4.0专属，官方，2026-08-18 补全）**：
- 内容用连贯自然语言（主体+行为+环境），美学用短词语（风格/色彩/光影/构图）
- 写明图像用途与类型（用于漫画分镜/PPT封面等）提升场景适配度
- 图内文字用""引号；专业词汇用词源语言更准
- 比例可在prompt直写，也可由模型按场景自动推理
- 「一系列/组图/帮我生成几张图」触发组图（最多10张）
- ★一致性：需保持角色形象/风格 → 输入图像作参考保持一致；多参考图时明确每张参考什么（"将图1中的角色放入图2的背景中，参考图3的风格"）
- 编辑类指令公式：变化动作+变化对象+变化特征（将骑士的头盔变为金色）

**开通坑**：3.0/3.1 套餐不含 4.0，须在官方文档页(85621/1817045)点「开通」进火山控制台开通（按量付费）；报 `50400 Access Denied` = 服务没开到API上（参数错是50215，别搞混）。

## 二、调用套路（两个 API 完全一致）

同一网关、同一套鉴权、同一套异步流程：

```
接口地址: https://visual.volcengineapi.com   (POST, application/json)
鉴权: AK/SK + V4签名, Region=cn-north-1, Service=cv  ← SDK 自动搞定
流程: 提交任务 → 拿 task_id → 轮询结果 → 取图
```

### 第一步：提交任务
- Query: `Action=CVSync2AsyncSubmitTask&Version=2022-08-31`
- Body 必带 `req_key`，其余见各 API 参数表
- 返回 `data.task_id`

### 第二步：查询任务
- Query: `Action=CVSync2AsyncGetResult&Version=2022-08-31`
- Body: `req_key` + `task_id` + 可选 `req_json`
- `req_json` 里可放：`{"return_url": true}`（以URL返回，24h有效，jpeg格式）、`logo_info`（水印，默认不加）

### 判断逻辑（官方强调，反了会 panic）
```
1. 先看外层 code == 10000 才算请求成功
2. 再看 data.status:
   in_queue(排队) → generating(生成中) → done(完成)
   not_found / expired(12小时过期) → 报错
3. done 后从 image_urls 或 binary_data_base64 取图
```

### 鉴权与 SDK（★实测踩坑，2026-08-18）
- AK/SK 获取：https://console.volcengine.com/iam/keymanage （**必须用「Access Key」标签页**：AK 以 `AKLT` 开头、SK 是 base64 串（结尾==）。⚠️别拿成「API Key」标签页的单长token——它配 AK 用会报 `SignatureDoesNotMatch`）
- ★必须装**老包**：`pip install volcengine`（清华镜像有）
  ⚠️文档里提到的 `volcengine-python-sdk` 是新版 OpenAPI 套件（`volcenginesdk*` 命名空间，给 ECS/VPC 那类用的），**不含** visual 服务，装了也 `import volcengine` 不了
- ★SDK 方法名：`cv_sync2async_submit_task` / `cv_sync2async_get_result`（sync2 和 async 之间**没有**下划线）
- 核心代码骨架：

```python
from volcengine.visual.VisualService import VisualService

svc = VisualService()
svc.set_ak("AK")
svc.set_sk("SK")

# 提交
resp = svc.cv_sync2async_submit_task({
    "req_key": "jimeng_t2i_v31",   # 或 jimeng_i2i_v30
    "prompt": "...",
    # ... 其他参数
})
assert resp["code"] == 10000
task_id = resp["data"]["task_id"]

# 轮询（2~3秒一次）
import json
resp = svc.cv_sync2async_get_result({
    "req_key": "jimeng_t2i_v31",
    "task_id": task_id,
    "req_json": json.dumps({"return_url": True}),
})
```

## 三、文生图3.1（jimeng_t2i_v31）参数

| 参数 | 类型 | 说明 |
|---|---|---|
| prompt | string 必选 | 中英文均可；**建议≤120字符**，最长800，过长易出图异常 |
| use_pre_llm | bool 可选 | 文本扩写。**短prompt开（默认true），长prompt关** |
| seed | int 可选 | 默认-1随机；同正整数+同参数 → 极大概率一致 |
| width/height | int 可选 | 需成对传；默认1328×1328 |

**尺寸规则**：宽高比 1:3 ~ 3:1，宽高乘积 [512×512, 2048×2048]

**提示词心法（官方建议，2026-08-18 补全）**：
- **内容用连贯自然语言**（主体+行为+环境），**美学用短词**（风格/色彩/光影/构图）——两种写法别搞反
- **写明用途与类型**：如「条漫分镜」「海报设计」「纪实摄影」，模型会对口增强
- 专业词汇用**英文/词源语言**更准
- 图内文字用引号：上面写着"boom"
- 表达准确的前提下，**短 prompt 反而效果好**

| 档位 | 1:1 | 4:3 | 3:2 | 16:9 | 21:9 |
|---|---|---|---|---|---|
| 标清1K | 1328×1328 | 1472×1104 | 1584×1056 | 1664×936 | 2016×864 |
| 高清2K | 2048×2048 | 2304×1728 | 2496×1664 | 2560×1440 | 3024×1296 |

## 四、图生图3.0智能参考（jimeng_i2i_v30）参数

**输入图硬性限制**：
- 仅 JPEG/PNG（建议 JPEG）
- ≤4.7MB，分辨率 ≤4096×4096
- **长边:短边 ≤ 3:1**，超了直接报错

| 参数 | 类型 | 说明 |
|---|---|---|
| binary_data_base64 / image_urls | 必选二选一 | 1张图的base64数组 或 URL数组 |
| prompt | string 必选 | 编辑指令，自然语言即可，≤120字符 |
| scale | float 可选 | **编辑强度 0~1，默认0.5，越大越听指令**（效果不明显就调大） |
| seed | int 可选 | 同上 |
| width/height | int 可选 | 需成对传，范围[512,2016]；实际输出=最接近16倍数的值，范围[512,1536] |

**prompt 技巧（官方建议，2026-08-18 补全）**：
- 海报/设计场景加「海报」「平面设计」等词
- 想让图上出现文字 → **用引号包住**：`一张圣诞卡片，上面写着"Merry Christmas"`
- 每次编辑用**单指令**效果更好
- 局部编辑时描述精准：画面有多个实体时说清"对谁做什么"
- 编辑不明显 → 调大 scale；**底图越清晰高分辨率效果越好**
- ★**用 AI 生成图（豆包/即梦出的图）当底图，编辑效果更好**——咱们的流水线（3.1出图→3.0编辑）天然满足这条

**指令模板**：
| 类型 | 写法示例 |
|---|---|
| 添加/删除实体 | 删除图上的女孩 / 添加一道彩虹 |
| 修改实体 | 把手里的鸡腿变成汉堡 |
| 改风格 | 改成漫画风格 |
| 改颜色 | 把衣服改成粉色的 |
| 改动作表情 | 让他哭/笑/生气 |
| 换背景 | 背景换成海边 / 在星空下 |
| 添加文字 | 一张圣诞节海报，上面写着"Merry Christmas" |

## 九、交互编辑 inpainting（jimeng_image2image_dream_inpaint）—— 局部重绘/消除笔

即梦「局部重绘」「消除笔」同款：原图 + mask + prompt → 仅 mask 白区重绘，黑区像素级保留。同网关同 SDK 同异步流程。2026-08-18 已实测：星铁卡面 5 处文字一次消除+替换为统一藤蔓花纹装饰，角色区零漂移；★风格类 prompt 会让模型把装饰往整框统一（不止 mask 区）；官方版权图本次未触发输入版权审核(50518)，但不保证次次过。

**输入**：binary_data_base64 / image_urls 传 **2 张图、尺寸须一致**：[原图, mask]；mask 为单通道灰度图，保持=0(黑)、重绘=255(白)。图 ≤4.7MB、≤4096×4096，仅 JPEG/PNG（建议 JPEG）。

**prompt** ≤120 字符：消除场景直接写「删除」；编辑场景自然语言描述预期内容，文字修改用""引号包住。
**seed** 可选，**默认 101**（3.x 是 -1，别以为写错）。
**开通**：console.volcengine.com/ai/ability/detail/2 单独开通；50400 = 没开通。

**漫画定位**：与 4.0 互补——4.0 产整格分镜，inpaint 做局部修补（只改表情、修崩手、去掉杂物），黑区不漂移，天然适合出格后精修；i2i 3.0 全图编辑仍弃用。

## 六、错误码速查

| code | 含义 | 处理 |
|---|---|---|
| 10000 | 成功 | - |
| 50411 | 输入图审核不过 | 换图 |
| 50412/50413 | 输入文本审核不过（敏感词/版权词） | 改prompt |
| 50511/50519 | 输出图审核不过 | **可重试** |
| 50429/50430 | QPS/并发超限 | 等几秒重试 |
| 50500/50501 | 服务内部错误 | 过会再试 |

出错时记下 `request_id`（排查关键凭据）。

## 七、做漫画的组合打法（2026-08-18 定稿）

```
阶段1 定妆     3.1 出主角立绘(角色卡prompt, 关扩写) → 抽卡选定"定妆照"
              ↳ 可出多视角(正面/侧面/全身)多张, 都当参考图
阶段2 分镜     4.0 参考生图: [定妆照×1~3 + 分镜场景prompt]
              "参考图中的少女在便利店门口撑伞回头" → 同角色新场景
              ↳ 单图模式 force_single=true; 也可试组图模式一次出一页
阶段2.5 修补   inpaint 局部重绘: mask只盖问题区域(崩手/表情不对/多余道具)
              ↳ 消除笔prompt写"删除"; 黑区像素级保留, 无全图漂移
阶段3 排版     多格拼接 + 对白气泡/拟声词
              ↳ 图内出字虽支持（引号法）但不可控，对白建议后期排版加字
```

**升级注记**：原方案 i2i 3.0 已弃用（写实AI感重、改表情诡异——死穴是脸部重绘）；纯角色卡+种子是下限方案。**4.0 参考生图 = 一致性正解**，实测 `anime_ref.jpg` → 雨夜便利店新场景同角色（2026-08-18）。
