## 今日学习内容

### 1. 什么是 DOM
- DOM = Document Object Model（文档对象模型）
- 浏览器把 HTML 解析成一棵树，每个标签都是一个节点
- JavaScript 通过 `document` 对象来操作这棵树

### 2. 选择元素
| 方法 | 说明 |
|------|------|
| `document.getElementById('id')` | 按 ID 选一个 |
| `document.querySelector('.class')` | CSS 选择器，返回第一个 |
| `document.querySelectorAll('tag')` | CSS 选择器，返回所有 |
| `document.getElementsByClassName('class')` | 按类名选（返回集合） |
| `document.getElementsByTagName('tag')` | 按标签名选（返回集合） |

### 3. 修改内容
| 属性/方法 | 说明 |
|-----------|------|
| `el.textContent` | 纯文本内容 |
| `el.innerHTML` | HTML 内容（可解析标签） |
| `el.style.color = 'red'` | 修改样式 |
| `el.setAttribute('attr', 'val')` | 设置属性 |
| `el.getAttribute('attr')` | 获取属性 |
| `el.classList.add('name')` | 添加 CSS 类 |
| `el.classList.remove('name')` | 移除 CSS 类 |
| `el.classList.toggle('name')` | 切换 CSS 类 |

### 4. 增删节点
| 方法 | 说明 |
|------|------|
| `document.createElement('tag')` | 创建元素 |
| `parent.appendChild(child)` | 添加到末尾 |
| `parent.insertBefore(new, ref)` | 插入到参考元素前 |
| `el.remove()` | 删除元素 |
| `parent.removeChild(child)` | 删除子元素 |

### 5. 事件
| 事件 | 触发时机 |
|------|---------|
| `click` | 点击 |
| `dblclick` | 双击 |
| `mouseenter` | 鼠标移入 |
| `mouseleave` | 鼠标移出 |
| `keydown` | 按下键盘 |
| `keyup` | 松开键盘 |
| `input` | 输入框内容变化 |
| `change` | 表单值改变（失焦后） |
| `submit` | 表单提交 |
| `dragstart` | 拖拽开始 |
| `dragover` | 拖拽经过 |
| `drop` | 放下 |
| `dragend` | 拖拽结束 |

**绑定事件：**
```javascript
el.addEventListener('click', function(e) {
    console.log('点击了', e.target)
})
```

### 6. 遍历 DOM 树
| 属性 | 说明 |
|------|------|
| `el.parentElement` | 父元素 |
| `el.children` | 所有子元素 |
| `el.firstElementChild` | 第一个子元素 |
| `el.lastElementChild` | 最后一个子元素 |
| `el.nextElementSibling` | 下一个兄弟元素 |
| `el.previousElementSibling` | 上一个兄弟元素 |

### 7. 拖拽排序关键点
- 用 `draggable="true"` 让元素可拖
- 4 个事件：`dragstart` → `dragover` → `drop` → `dragend`
- `dragover` 必须 `e.preventDefault()` 才能接收 drop
- 用鼠标 Y 坐标和元素中点比较，决定插入位置

## 前端术语速查

| 术语 | 含义 |
|------|------|
| **DOM** | Document Object Model，页面的树形结构 |
| **BOM** | Browser Object Model，浏览器相关（window、location） |
| **事件冒泡** | 子元素的事件会向上传播到父元素 |
| **事件委托** | 利用冒泡，把事件绑在父元素上（性能优化） |
| **盒模型** | content + padding + border + margin |
| **Flexbox** | 弹性布局（`display: flex`） |
| **回调函数** | 传给另一个函数执行的函数 |
| **选择器** | `#id`、`.class`、`tag` 这些匹配规则 |
| **伪类** | `:hover`、`:focus` 表示元素特殊状态 |
| **伪元素** | `::before`、::after` 创建虚拟元素 |
| **响应式** | 页面自适应不同屏幕尺寸 |
