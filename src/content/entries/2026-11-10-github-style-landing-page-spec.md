一套可以直接丢给 AI（或自己照着写）的落地页构建提示词，目标：**1:1 深度致敬 GitHub 官网首页**的工业级质感。技术栈 Next.js (React) + Tailwind CSS + Framer Motion。

## 视觉基调：深空光影

- 背景：纯粹宇宙冷黑（`#040d21` → `#0d1117` 渐变）+ 微弱网格噪点 overlay
- 极光光斑：局部放超大模糊（`filter: blur(120px)`）的荧光蓝 / 紫罗兰 / 青绿光雾，撑出浩瀚感
- 卡片：1px 半透明磨砂边框（`rgba(255,255,255,0.1)`），悬停时边缘出现**跟随鼠标的径向微光**

## 页面五段结构

1. **吸顶导航**：全宽毛玻璃（`backdrop-blur-md`）；左 Logo、中间极简链接、右侧带键盘快捷键 `/` 的圆角搜索框 + 渐变高亮登录按钮
2. **Hero 巨幅区**：超大 H1 用白银→浅青渐变文字（`text-transparent bg-clip-text`）；双 CTA——主按钮发光实色胶囊，次按钮幽灵线框带箭头平移悬停；右侧放交互式 3D 发光地球，或一个**实时流式打字的 AI 代码补全编辑器界面**
3. **光纤生命线（全页灵魂）**：屏幕左侧一条垂直贯穿整页的微光细线，随滚动**逐渐充能点亮**，在每个功能区块交汇处亮起发光脉冲节点徽章
4. **Bento 功能网格**：不对称 2×2 / 3×3；卡片内不放静态文字，放**活的极客微界面**——Git PR 红绿 diff、CI/CD 流水线节点流动动画、绿光标闪烁的终端窗口
5. **背书与页脚**：平滑滚动的 Logo 走马灯 + 极简多列 Footer

## 动效与纪律

- Framer Motion：滚动渐入（fade-in + slide-up）、视差微动效
- **禁止任何 Emoji**，图标一律 Lucide-react 单色精密线框
- 字体锁死：正文 Inter 或 Geist Sans，代码与数据 JetBrains Mono

## 一句话复用

> 深空黑 + 极光模糊光斑定调，光纤生命线串场，Bento 卡片全部塞「活界面」，Lucide 图标 + 双字体锁定——照这四条写，出来的就是「GitHub 级」而不是「模板级」。
