## 二、ACM 模式速成（笔试 / 卡码网用）

**两种模式对比**：

| | ACM 模式（笔试/OJ） | 函数模式（LeetCode/手撕） |
|---|---|---|
| 输入 | 自己读 stdin | 面试官给函数签名 |
| 输出 | 自己 print 按格式 | return 即可 |
| 额外工作 | **自己构建链表/二叉树** | 平台帮你构建好 |
| 难度增量 | 纯熟练度 | 无 |

**万能 Python 模板（主练 Python，写得快）**：

```python
import sys

def solve(data):
    # 算法逻辑
    pass

def main():
    data = sys.stdin.read().split()   # 一次性读入所有 token，最通用
    # data[0], data[1]... 全是字符串，按需 int()
    print(solve(data))

main()
```

**四种常见输入形态**：

```python
# ① 单行空格分隔：3 5
a, b = map(int, input().split())

# ② 第一行 n，接下来 n 行每组数据
n = int(input())
for _ in range(n):
    row = input().split()

# ③ 多组用例直到 EOF（不确定组数）
for line in sys.stdin:
    nums = list(map(int, line.split()))

# ④ 逗号分隔：1,2,3
nums = list(map(int, input().split(',')))
```

**输出**：`print(' '.join(map(str, res)))`（空格分隔）或逐行 print（换行分隔）——**看样例输出格式抄格式**。

**坑与技巧**：
- 本地必须拿样例输入自测再提交
- 卡码网题目评论区常有现成输入输出模板（虾皮复用题库：352、CodeFun2000 P2790）
- 链表/树题在 ACM 模式下要按题意自己构建，LeetCode 习惯者在这里最容易翻车——专项练 2 道即可

## 三、面试手撕完整流程（重点）

### 3.1 形式
- **载体**：牛客/赛码在线 IDE（能运行）、共享文档（腾讯文档/飞书，纯写不能跑）、线下白板
- **模式**：绝大多数是**函数模式**，不碰输入输出
- **大数据岗特别版**：手撕 SQL（给表结构写查询）出现频率最高

### 3.2 标准五步（面试官打分点）

| 步骤 | 时间 | 动作 | 加分/减分 |
|---|---|---|---|
| ① 读题确认 | 1-2min | 复述题意 + 问边界：数据规模？重复？空输入？ | 主动问=工程素养；不问就写=危险信号 |
| ② 讲思路 | 2-3min | 先暴力解+复杂度，再优化解，**面试官点头再写** | 闷头写是大忌 |
| ③ 写代码 | 10-20min | 边写边解说；命名清晰；卡壳就说"先搭框架再补细节" | 说出来的思考过程也在被评分 |
| ④ 自测 | 2-3min | 主动造 2-3 个用例走一遍（正常/边界/空） | **自己抓出自己的 bug = 强加分** |
| ⑤ 追问 | 视情况 | 复杂度分析、能否优化、变体 | TopK→第K大→流式TopK 是经典追问链 |

### 3.3 卡住保命话术
- "我先说下暴力解法，您看这个方向可以吗？"——先拿基础分
- "这里我想一下，能给点提示吗？"——**要提示不丢分，沉默五分钟才丢分**
- 小例子手工模拟（n=3 手推）找规律
- 实在写不完：思路/伪代码讲完整，过程分也在

### 3.4 虾皮大数据岗手撕预测（按面经概率排序）

1. **手写 SQL**（最高频，共享文档写）：
   - 窗口函数 TopN：每组第N高（row_number/rank/dense_rank 辨析）
   - 连续登录 N 天：lag/lead + 日期差分
   - 留存率：自 join + 条件计数
   - 已有题库：《2026-09-04_虾皮面试题集》SQL 6 题
2. **算法**（函数模式，LeetCode 难度 easy~medium）：
   - TopK（小顶堆 / 快排 partition）
   - LRU（OrderedDict / 双向链表+哈希）——面经原题
   - 反转链表、两链表求和（笔试考过）、countSegments 类字符串题
3. 手写代码规范：`def` + 类型注解、 meaningful 命名、关键处注释

### 3.5 两周训练计划（建议）

| 天数 | 任务 | 目标 |
|---|---|---|
| D1-D2 | 卡码网 ACM 入门题 ×10（每道套同一模板） | ACM 脱敏，模板默写 |
| D3-D5 | SQL 三件套各写 3 遍（TopN/连续登录/留存率） | 默写级 |
| D6-D10 | 每日 1 题**对着空白文档写+口述**（LRU/TopK/链表/字符串轮换） | 习惯边写边说 |
| D11-D14 | 模拟面试（可找我练）：连环追问 + 变体 | 抗压 |
