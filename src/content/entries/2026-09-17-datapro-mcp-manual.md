## 0. 通用说明

### 唯一入口

MCP 只有一个工具 `dataPro_search`，入参就一个自然语言 `query` 字符串，后端自动路由到对应数据集。

### 通用返回结构

```json
{
  "code": 0,              // 0=成功；4011=方舟鉴权失败(key/额度/权限)
  "msg": "success",
  "trace_id": "xxx",      // 排障用，报错时提供给火山
  "dataset_type": "xxx",  // 命中的数据集标识（见下表）
  "items": [ ... ],       // 数据本体，各库结构不同
  "hint": ""              // 提示（如"请输入完整车型名称精确查询"）
}
```

| dataset_type | 数据集 |
|---|---|
| `academic_search` | 学术文献库 |
| `enterprise_info` | 企业工商信息库 |
| `enterprise_risk` | 企业风险库 |
| `stock_finance` | 股票金融库 |
| `vehicle_config` | 汽车配置库 |
| `vehicle_sales` | 汽车销量库 |
| `other_datasets` | 其他综合（政策/新闻/百科） |

### 通用注意事项

1. **一次只问一个意图**——别把工商、诉讼、金融混在一句里，会路由失败或命中错误库
2. **结果可能非常大**——企业工商查"字节跳动"返回 87K 字符、汽车配置一查一整个车系；超限会自动存成本地文件，最好让 AI 抽取关键字段而不是全文输出
3. **实体写规范名**——公司用简称或统一社会信用代码；查不到时后端会提示
4. 多企业查询可在一句话里列 1~5 家，超过 5 家拆分调用

## 1. 学术文献库 `academic_search`

**覆盖**：CNKI（知网）、万方、维普、arxiv、PubMed、MDPI、Biorxiv 等全球主流学术平台。
**入参写法**：`研究主题 / 论文关键词`，中英文皆可，可加"综述/论文"等词辅助。

### 返回字段（每条文献）

| 字段 | 说明 | 实测样例 |
|---|---|---|
| `name` | 论文标题 | A comprehensive survey of hallucination mitigation... |
| `url` | 原文链接（多为 PDF） | https://arxiv.org/pdf/2401.01313 |
| `date_published` | 发表日期 | 2024-01-01 |
| `snippet` | 命中片段 | ...survey of over thirty-two techniques... |
| `abstract` | 完整摘要（部分期刊无） | ... |
| `extra_data.authors` | 作者列表（截断） | SM Tonmoy, SM Zaman, V Jain... |
| `extra_data.cite_by` | **被引数** | 1031 |
| `extra_data.doi` | DOI | https://doi.org/10.48550/arxiv.2401.01313 |
| `extra_data.journal_title` | 期刊名 | arXiv (Cornell University) |
| `extra_data.volume` / `issue` / `first_page` / `last_page` | 卷/期/页码 | 57 / 9 |
| `extra_data.pdf` | 是否有 PDF（1/0） | 1 |

**默认返回 10 条**（`returned_count` 字段可见）。`cite_by` 可以直接用来筛高引综述。

## 2. 企业工商信息库 `enterprise_info`

**覆盖**：企业基础档案、法人、股东、注册资本、经营范围、企业简介、知识产权、舆情汇总等。
**入参写法**：`公司简称 公司档案` 或 `查询XX、YY和ZZ的工商信息`（最多 5 家）；查不到就换统一社会信用代码。

### 返回字段（每家企业 47 个字段）

| 分类 | 字段 |
|---|---|
| **标识** | 公司ID、公司名称、统一社会信用代码、注册号、组织机构代码、行政区域代码 |
| **法人** | 法人姓名、法人类型、法定代表人的类型名称、法人ID |
| **注册** | 注册地址、注册资金、实收注册资金、注册资本数值(元)、实缴资本数值(元)、成立日期、营业期限开始日期、企业状态、登记机关、核准日期 |
| **地域** | 归属省份首字母小写、所在省份名称、所在城市名称、所在区县名称、省、市、区/县 |
| **行业** | 行业代码、所属行业、产业一级/二级/三级分类名称 |
| **简介** | 企业名称（企业简介）、企业简介 |
| **关联信息(JSON字符串)** | 主要人员记录、企业邮箱记录、股东信息记录 |
| **大礼包** | 工商经营信息、知识产权信息、投资人信息、新闻舆情汇总 |
| **全量下载** | 知识产权信息/投资人信息/工商经营信息 各带"全量下载地址"（带 token 的临时 URL） |

实测样例：查"字节跳动"命中 5 家子公司（河南/南京/无锡/广州/山东），含法人、注册资本、股东明细等。
⚠️ 注意：**模糊名会命中一堆子公司，不一定是你要的主体**，精确主体请用全称或信用代码。

## 3. 企业风险库 `enterprise_risk`

**覆盖**：司法诉讼、失信、限高、经营异常、处罚、税务、清算、破产、舆情等。
**入参写法**：`公司 风险维度`，如 `字节跳动 失信被执行人信息`、`查询小米和字节跳动的经营风险`；维度要写具体（诉讼/失信/经营异常/舆情），别笼统问"这家公司怎么样"。

### 返回字段（每家企业一个大 JSON，约 300+ 字段，按块理解）

#### 3.1 企业基本识别

| 字段 | 说明 |
|---|---|
| 企业唯一ID / company_id字符串 | 企业主键 |
| 统一社会信用代码 / 企业名称 / 企业简称 | 主体标识 |
| 法定代表人姓名 / 法人唯一标识 | 法人 |
| 清洗后完整注册地址 / 注册省份 / 注册城市 / 注册区县 | 注册地 |
| 一级/二级/三级行业名称、一/二/三产业 | 行业 |

#### 3.2 四个总开关（1有 0无）

`是否有失信记录` / `是否有欠税记录` / `是否有经营异常记录` / `是否有税收违法记录`、`企业有效标记`(仅1为有效大陆主体)

#### 3.3 风险计数矩阵（核心）

约 **17 类风险 × 统一模板**：`最早发生日期` / `最新发生日期` / `总条数` / `近30天条数` / `近60天` / `近90天` / `近180天` / `近1年(365天)条数`

| 风险类别 | 备注 |
|---|---|
| 经营异常 | |
| 动产抵押 | 另有 被担保债权总额/概况数额(元) 各时间窗 |
| 股权出质 | 另有 出质总额(元) 各时间窗、pledge_cnt_1y |
| 司法拍卖 | |
| 抽查检查 / 双随机抽查 | |
| 注销备案公告 / 简易注销 | |
| 清算信息 | 只有总条数 |
| 破产重整 | |
| 环保处罚 | 另有 罚款合计(元) 各时间窗 |
| 税收违法 / 行政处罚 | 行政处罚另有 罚款/违约金/没收金额 各时间窗 |
| 纳税非正常户 / 纳税信用 / 欠税 | 欠税另有 金额/余额/新发生余额；纳税信用按年度 |
| 严重违法 | |

#### 3.4 明细（每类"最新前5条"）

各风险类别的 `最新前5条明细` / `TOP5，按时间倒序`：JSON 字符串，含序号、风险类型、来源表、检查部门/法院、日期、结果等。

#### 3.5 司法诉讼信息块（有诉讼记录的企业才出现）

| 字段组 | 内容 |
|---|---|
| 角色计数 | 立案-原告/被告/第三人/其他 案件数、开庭公告-原告/被告/第三人数、法院公告各角色数、裁判文书-原告/被告/被上诉人/被执行人/申请人数 |
| 总计 | 立案总案件数、开庭公告总数、法院公告总数、裁判文书总数、**司法诉讼总数** |
| 高危标签 | **作为被执行人的案件数 / 限制高消费案件数 / 失信被执行人案件数**、破产重整计数、终本案件计数、司法拍卖案件数 |
| TOP5 明细 | 立案/开庭/裁判文书/被执行/限高/失信/破产/终本 各 TOP5（案号、案由、原被告、法院、时间、审判结果、标的金额） |

#### 3.6 其他

| 字段 | 说明 |
|---|---|
| 新闻舆情汇总 | 舆情列表 |
| 司法诉讼全量数据下载地址 / 企业风险信息全量数据下载地址 | 带 token 的全量下载 URL |
| ADS表入库加载时间 | **数据新鲜度**（实测 2026-07/08 更新） |

⚠️ 注意：`null` ≠ 0，多数情况表示"无该类记录"；真正干净的判断看 3.2 的四个 0/1 开关。

## 4. 股票金融库 `stock_finance`

**覆盖**：国内外股票/基金/期货/期权/债券/外汇的行情、市盈率、财务指标等。
**入参写法**：`证券代码/规范名称 + 时间范围或指标`，如 `贵州茅台(600519.SH) 最近一周价格`、`000001.SZ 最近一周的价格`。

### 返回字段（行情类，实测日线）

| 字段 | 说明 |
|---|---|
| `证券代码` | 300850.SZ |
| `time[]` | 交易日数组 |
| `table.开盘价 / 最高价 / 最低价 / 收盘价` | OHLC |
| `table.涨跌` | 涨跌额 |
| `table.涨跌幅` | 百分比 |
| `table.成交量` | 手 |
| `table.成交额` | 元 |
| `table.换手率` | % |

按官方说明还支持：开/收盘价、市盈率、总股本、净利润、财务指标、财报报告期等（财务类直接问"XX 市盈率/净利润"即可路由）。

## 5. 汽车配置库 `vehicle_config` ⭐字段最全

**覆盖**：品牌、厂商、车系、车型、年款、指导价、动力、电池、续航、智驾、安全、座舱等全量参数（类似汽车之家配置表，`●`标配 / `○`选装 / `-`无）。
**入参写法**：`车系 + 年款`（如"比亚迪汉EV 2025款 车型配置"）；要精确到某一款时用**完整车型名称**。

### 返回结构

外层每款车 6 个字段：`车型编码`、`品牌`、`厂商`、`车系`、`车型名称`、`年款` + 一个 `车型完整配置JSON`（~230 个配置项）。一次查询返回同车系多款车型。

### 车型完整配置 JSON 字段分类（~230 项）

| 分类 | 典型字段 |
|---|---|
| **基础** | 指导价、销售状态(在售/停售)、厂商属性(自主/合资)、车型级别、燃料类型、排放标准、上市日期、车身类型、整车质保 |
| **动力性能** | 最大功率(kW)、最大扭矩(N·m)、官方0-100km/h加速(s)、最高车速、电能当量燃料消耗量 |
| **车身尺寸** | 长/宽/高/轴距、前后轮距、接近/离去角、最小转弯半径、风阻系数、车身结构、座位数、后备厢/前备厢容积 |
| **电机三电** | 电动机品牌/型号/类型、总功率/马力/扭矩、驱动电机数、电机布局 |
| **电池充电** | 电池类型、电芯品牌、电池特有技术(刀片)、**CLTC纯电续航(km)**、电池能量(kWh)、能量密度、百公里耗电量、快充功率(kW)、快充时间、**高压平台(V)**、电池冷却方式、对外放电功率 |
| **变速箱底盘** | 变速箱类型、驱动方式、前/后悬架类型、前/后制动器类型、驻车制动、轮胎规格、备胎 |
| **被动安全** | 主副驾/侧/头部气帘/膝部/前排中间气囊、ABS、EBD、牵引力控制、车身稳定、胎压监测、ISOFIX |
| **主动安全** | 车道偏离预警、主动刹车、疲劳驾驶提示、DOW开门预警、前/后方碰撞预警、哨兵模式、内置行车记录仪 |
| **智能驾驶** | **辅助驾驶芯片**(英伟达 Orin-N/X)、**芯片总算力(TOPS)**、前方感知摄像头类型、摄像头/车内摄像头/超声波/毫米波/**激光雷达数量**、巡航系统、辅助驾驶系统(DiPilot 100/300)、辅助驾驶等级、记忆泊车、辅助变道、辅助匝道、辅助驾驶路段、前方最大探测距离 |
| **座舱车机** | 中控屏尺寸/类型/分辨率、车机智能芯片、车机内存/存储、车载智能系统(DiLink)、语音助手唤醒词/分区识别/连续识别、4G/5G、OTA、手机APP远程功能清单、HUD、全液晶仪表尺寸、面部识别、车载KTV、后排屏幕 |
| **灯光外观** | 近/远光灯光源、自适应远近光、天窗类型、隐藏门把手、钥匙类型、外观套件 |
| **座椅** | 座椅材质、主/副驾调节方式、前排座椅功能(加热/通风/按摩)、电动座椅记忆、第二排功能 |
| **音响** | 扬声器品牌(丹拿等)、喇叭数量 |
| **空调舒适** | 自动空调、热泵空调、后排独立空调、车载空气净化器、PM2.5过滤、负离子、车内香氛、**车载冰箱**、空气质量监测 |
| **颜色** | 外观颜色、内饰颜色 |
| **🎁 附赠销量** | 车系最近第1~6个月 年月+销量（与销量库联动） |

⚠️ 注意：尾部有 `地暖`、`车顶帐篷` 两个数据源模板残留脏字段，忽略。

## 6. 汽车销量库 `vehicle_sales`

**覆盖**：按年月、统计层级（品牌/厂商/车系）、地域聚合的销量。**自主/新势力/豪华/合资/进口都能查**（奥迪/宝马/特斯拉实测 OK）。
**入参写法**：`品牌/厂商/车系 + 年月 (+ 口径/地域)`，如"比亚迪 2026年8月 汽车销量"、"奥迪A6L 2026年8月 销量"、"特斯拉 2026年8月 中国销量"。

### 返回字段

两种结构，按品牌类型自动切换：

**① 国产新能源品牌（如比亚迪）——NEV 细分指标结构**

| 字段 | 说明 | 实测样例 |
|---|---|---|
| `查询条件.品牌 / 统计年月` | 回显查询条件 | 比亚迪 / 2026-08 |
| `销售数据[].指标名称` | 指标 | 新能源汽车销量、新能源乘用车销量、纯电动乘用车销量、插电式混合动力乘用车销量、新能源商用车/客车销量、**出口新能源汽车销量**、合计销量 |
| `销售数据[].本月销量` | 当月 | 440293 |
| `销售数据[].去年同期销量` | 同比基数 | 373626 |
| `销售数据[].本年累计销量` | 累计 | 2668015 |
| `销售数据[].单位` | — | 辆 |

**② 其他品牌（豪华/合资/进口，如宝马/奥迪/特斯拉）——统计口径结构**

| 字段 | 说明 | 实测样例 |
|---|---|---|
| `查询条件.品牌/品牌车系 / 统计年月 / 地域` | 回显（地域：中国/全国） | 特斯拉 / 中国 / 2026-08 |
| `销售数据[].统计口径` | **零售/批发/出口/终端/零售量/批发量** | 批发销量、零售销量、出口销量 |
| `销售数据[].销量` / `单位` | 数值 | 86166 / 辆 |
| `销售数据[].同比` | 部分返回带同比 | -26.6%（奥迪） |
| `销售数据[].数据来源口径` / `数据性质` | 数据源标注 | 乘联会CPCA、**乘联分会初步数据** |

⚠️ **口径差异巨大**：特斯拉 8 月批发 86,166 vs 零售 50,047 vs 出口 36,119。做分析前先想清楚要哪种口径。

### 6.5 彩蛋：宏观市场 `macro`

问"乘用车市场总销量"这类总量问题会路由到 `macro` 数据集：

| 字段 | 说明 | 实测样例 |
|---|---|---|
| `数据时间` / `指标` | 期间+指标名 | 2026年8月 / 乘用车市场总销量 |
| `销量.value` / `unit` | 总量 | 238.3 万辆 |
| `同比` / `环比` | 增速 | -6.2% / +5.1% |
| `统计口径` | 主口径来源 | 中汽协产销口径 |
| `补充口径说明` | 多口径对比对象 | 乘联分会狭义乘用车国内零售 154.1万辆(-23.6%)、厂商批发 235.3万辆 |

## 7. 其他综合库 `other_datasets`

**覆盖**：新闻资讯、政策解读、百科常识、事件追踪、综合事实问答。
**入参写法**：自然语言直接问，如"新能源汽车 购置税减免 政策"。

### 返回字段（政策类实测，`answer_type: policy`）

| 字段 | 说明 | 实测样例 |
|---|---|---|
| `answer_type` | 答案类型 | policy |
| `data.policy_name` | 政策全称+文号 | 关于延续和优化新能源汽车车辆购置税减免政策的公告（2023年第10号） |
| `data.issuer` | 发文单位 | 财政部、税务总局、工业和信息化部 |
| `data.issue_date` / `effective_date` | 发文/生效日期 | 2023-06-19 / 2024-01-01 |
| `data.scope` | 适用范围 | 纯电、插混（含增程）、燃料电池车 |
| `data.key_clauses[]` | **核心条款逐条列出** | 2024-2025免征（上限3万/辆）、2026-2027减半（上限1.5万/辆）… |
| `data.penalties` | 违规处理 | 依税收征管法处理 |
| `data.summary` | 一句话总结 | — |

新闻/百科类结构类似：结构化摘要 + 关键条目，非原始网页堆砌。
